# TouchDict

当前版本：**1.4**。

## 1.4 更新

- 主窗口与查词卡片使用内嵌 WebView2 界面，统一边缘留白、按钮和词性标签。
- 支持切换 Gemini 与本地 GGUF 模型，并提供本地模型设置和托盘切换入口。
- 原句读取改用独立进程中的 Windows 原生 UI Automation 接口，绕过 .NET 文本读取崩溃。
- 查词卡片按屏幕可用高度展开，在屏幕边角自动调整位置；修正结果区额外留白导致的滚动条。
- 收紧选词与上下文的释义边界，拒绝词条不一致或例句不含所查词的结果；旧提示词缓存保留在历史中，新查询重新生成。
- Release 提供单独 EXE 和包含本地推理运行时的压缩包，模型文件需自行准备。小型本地模型的释义质量仍需使用者确认。

## 1.3 更新

- 卡片宽度按内容在 400–600px 之间调整，高度按内容增长，超过屏幕高度时滚动显示。
- 改善选区避让、屏幕边界约束及跨屏布局；复制提示为圆角半透明、1 秒淡入淡出。
- 历史记录支持自动朗读，沿用超过 3 个单词不自动播放的规则。
- 增加单实例限制并修正 Gemini 请求与结果解析。

## 主窗口

- 主窗口使用系统已有的 Microsoft Edge WebView2 Runtime，界面资源内嵌在 EXE 中，无需联网加载页面，也不附带另一份浏览器运行时。程序自动发现已安装版本，系统更新后无需修改版本路径。
- 双击托盘图标，或在托盘菜单选择“打开主窗口”。
- 在顶部输入英文后按 Enter 或点击“查询”。左侧显示最近使用的查询历史，右侧显示与划词卡片相同的释义、词性、例句和翻译。
- 主窗口查询和划词卡片共用同一份持久化结果集，最多保存 500 条；点击历史记录可直接查看保存结果，无需重新联网。
- 输入疑似拼错时，右侧会显示可点击的候选词；点击候选词立即查询对应内容。
- 关闭主窗口只会隐藏窗口，后台划词和托盘仍继续运行。
- 历史记录支持上下键选择、Delete 连续删除、清空确认以及导出 CSV；英文例句支持一键复制，当前结果支持朗读和绕过缓存重试。
- “固顶”可保持主窗口置顶；`Ctrl++` / `Ctrl+-` 调整词语和正文字号，`Ctrl+0` 恢复 30/12 pt，并同步查词浮窗字号。

## 开机启动

设置中的“开机自动启动”默认选中。开机登录后 TouchDict 只驻留托盘，不会自动弹出主窗口；取消选中并保存即可移除当前用户的启动项。

Windows 11/10 轻量划词词典。选中英文后按 `Ctrl+Alt+D`，或在 Windows 触摸板设置中把“三指轻点”映射为“左 Alt”。TouchDict 会调用 Gemini 返回上下文词义、词性、例句及翻译，并使用 Windows 美式英语语音朗读。

## 使用

1. 将 `gemini_key.txt` 与 `TouchDict.exe` 放在同一目录。
2. 运行 `TouchDict.exe`，程序常驻系统托盘。
3. 把鼠标悬停在英文单词上；也可以先划选一个单词或短语。
4. 三指轻点（Windows 映射为左 Alt）或按 `Ctrl+Alt+D`。没有现有选区时，TouchDict 会自动双击选择鼠标下的单词。
5. 托盘菜单可暂停监听、打开预览、设置密钥或退出。

## 说明

- 取词使用临时复制并恢复原来的文本剪贴板内容。某些受保护应用、远程桌面或不允许复制的控件可能无法取词。
- Windows 不向普通程序直接提供 Precision Touchpad 三指轻点事件，请把“三指轻点”映射为左 Alt。鼠标中键不会被 TouchDict 监听或拦截。
- 密钥从设置（DPAPI 加密）、`GEMINI_API_KEY` 环境变量或 EXE 同目录文件读取。
- 发音依赖 Windows 安装的 `en-US` 语音。
