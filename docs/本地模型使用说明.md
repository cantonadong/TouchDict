# 本地模型

在“设置 → 本地”中填写模型目录（默认 `D:\Models`），点击“检索”，从下拉框选择一个 GGUF 模型，再保存。保存时使用当前标签中的模型；切回“在线”标签可选择原有 Gemini 模型。

托盘右键菜单的“在线模型”和“本地模型”各有二级模型选项，鼠标移到菜单上即可选择。菜单显示当前模型，选择后自动保存。

当前目录含 Gemma3-1B 和 Qwen3-0.6B。程序递归检索 `.gguf` 文件，不把语音识别模型当作查词模型。本地推理使用 CPU，首次查询需要加载模型；切换模型、退出软件时释放旧模型。加载与查询总超时为 90 秒。

本地查询不需要 API Key，不调用在线模型。Gemma、Qwen 与 Gemini 共用同一份查词提示词、上下文长度、温度（0.2）、输出上限（2048）及结果校验。Gemma 的模板使用单个用户消息承载相同的系统指令与查询文本；运行时直接约束 JSON 结构。学习说明要求 2–3 句，覆盖理解、记忆及实际用法；不会自动降级成缺少音标或翻译的结果。完整句子和拼写建议沿用 Gemini 的字段规则。

查词缓存、历史记录、次数和 CSV 导出与在线模式共用；只复用当前提示词版本的缓存。同一提示词不能保证不同模型具有相同能力，尤其是 0.6B、1B 的小模型，仍可能生成不准确的词性、释义或记忆提示；格式校验无法证明语义正确。

运行 `artifacts\TouchDict.exe` 时，请保留旁边完整的 `local-runtime` 文件夹。模型文件仍从配置目录读取，不复制到程序目录。日志：`%LOCALAPPDATA%\TouchDict\local-model.log`。

运行时为 [llama.cpp b11429 官方 Windows CPU 包](https://github.com/ggml-org/llama.cpp/releases/tag/b11429)，安装脚本校验 SHA-256。接口参数依据[官方 server 文档](https://github.com/ggml-org/llama.cpp/blob/b11429/tools/server/README.md)。仅监听 `127.0.0.1`，每次启动使用随机访问密钥。
