# TouchDict 主窗口 WebView2 迁移

## 目标与范围

将现有主窗口内容全部迁移到 Edge WebView2，以改善视觉排版和交互反馈，并保留所有现有功能。继续使用 Go 后端、Walk/Win32 窗口外壳及现有查询服务。此次不迁移查词浮窗和设置窗口，不改变模型、缓存、取词、全局快捷键和托盘行为。

直接在 main 工作，保留工作区已有修改。用户未要求测试，不运行自动化测试或自动化界面测试；编译完成后结束现有 TouchDict 进程并覆盖 artifacts/TouchDict.exe，交给用户实际试用。

## 技术方案及取舍

采用原生窗口中嵌入 WebView2 控件的方案，保留 mainwindow.Window 对外接口及 MW 窗口对象，使现有托盘、弹窗和主线程调度继续工作。HTML、CSS、JavaScript 随 EXE 内嵌，不加载远程页面、字体或 CDN，不启动本地 HTTP 服务。

相比迁移整个应用到新的桌面框架，此方案修改面较小，能够沿用当前窗口生命周期；相比只给原生控件换样式，能够完整控制内容排版、状态反馈和滚动。WebView2 需要额外的运行时和进程，首次初始化可能增加启动耗时。

WebView2 接入代码放在独立组件中，负责初始化、调整控件边界、消息收发、聚焦和销毁。组件初始化及 UI 修改都在 Windows UI 线程进行，并与现有消息循环兼容。

## 完整功能清单

- 搜索框输入单词、短语、句子；点击查询及 Enter 提交；空输入给出提示。
- 查询中禁止重复提交相同内容，允许提交不同内容；继续使用查询服务处理取消和过期结果。
- 完整显示空状态、查询中、成功、错误、拼写候选状态；候选词点击后填入搜索框并查询。
- 成功结果显示词语、词性、中文释义、英文例句、中文翻译；不存在的字段不占用空白区。
- 朗读当前词语；重试当前输入并绕过缓存；根据查询状态启用或禁用按钮。
- 复制英文例句到 Windows 剪贴板，成功显示短暂提示，失败显示可理解的错误。
- 显示历史记录、选择历史后填入输入框并显示结果，沿用后端历史统计与自动朗读。
- 历史列表支持键盘上下选择和 Delete 删除，包括按住 Delete 连续删除；刷新后保留选择，删除后选中相邻项。
- 清空历史保留确认操作、失败提示；CSV 导出保留 Windows 保存对话框、覆盖提示、中文 UTF-8 BOM、字段和查询次数。
- 固顶和取消固顶通过原生窗口实现；保留可调整大小、最小尺寸、最大化、最小化恢复、关闭隐藏和托盘重新打开。
- Ctrl 加号/减号同步调整词语及正文字号，Ctrl+0 恢复 30/12 pt；范围 8–72 pt；继续通过回调同步浮窗字号。
- 保存用户调整的窗口高度；长内容根据页面测量适当增加窗口高度，限制在可用屏幕范围内，剩余内容滚动展示。
- 打开或重新激活窗口时聚焦搜索框并全选；保留 --main-preview 现有入口。

## 界面

采用浅色背景、蓝色重点色、细边框和统一圆角。顶部搜索区，左侧历史列表，右侧词义和例句卡片。操作按钮和状态信息位置稳定，历史和结果分别滚动。窄窗口保持搜索和操作可用，长句自然换行。正文可选中复制。

CSS 使用系统字体，保留现有字号语义；加载动画轻量，减少布局跳动。清空和导出操作提供明显入口。键盘焦点清晰，图标按钮附带文字或可访问名称。

## 数据和消息

Go 保存当前输入、查询状态、历史、选中项、字号和固顶状态，向页面发送结构化 JSON 状态。页面通过 window.chrome.webview.postMessage 发送白名单动作；Go 验证动作及参数，再调用现有回调或原生操作。

页面完成初始化后发送 ready，Go 推送最新完整状态；初始化之前的 SetInput、SetHistory、Update 不丢失。普通结果刷新不重建输入框，不打断输入、焦点和选区；历史更新保留滚动位置。

查询文本、模型结果和历史内容以 textContent 渲染，不直接拼接为 HTML 或 JavaScript。禁止页面跳转和新窗口，禁用非必要浏览器菜单与默认页面缩放，避免与自定义字号快捷键冲突。

## 生命周期和故障

使用系统已安装的 Evergreen WebView2 Runtime，不下载或捆绑另一份运行时。用户已提供系统安装目录 `C:\Program Files (x86)\Microsoft\EdgeWebView\Application\153.0.4234.32`；通过官方 loader 自动发现已安装版本，避免系统更新后固定版本路径失效。检测缺失或初始化失败时给出明确中文提示。页面资源独立于网络加载，查词仍由 Go 完成。运行时用户数据放在应用专用的本地用户目录。

窗口隐藏后复用控件，不重复冷启动；退出时释放 WebView2 控件及环境引用，保证现有单实例及退出行为。初始化失败不展示无法操作的空白窗口。浮窗与设置不依赖迁移后的页面。

## 交付与验证

编译验证 Go 接口和 WebView2 集成依赖，不运行测试。覆盖同一个 artifacts/TouchDict.exe，并向用户提供路径和需要实际验证的主要功能：查询及候选、历史选择删除清空导出、朗读复制重试、固顶字号、窗口缩放与托盘重开。

编译成功不等于交互已经通过用户验证；最终交付明确区分编译结果和待用户实际验证的行为。
