# 免费在线模型

TouchDict 支持 Gemini、Groq 和 OpenRouter。在线服务的免费使用均有额度和频率限制，不代表永久无限免费；限额和模型供应可能调整。以下入口核对于 2026-10-11。

| 平台 | 应用内模型 | Key 申请 |
| --- | --- | --- |
| Gemini | 现有 Gemini 模型 | https://aistudio.google.com/apikey |
| Groq | GPT-OSS 20B、GPT-OSS 120B、Qwen 3.8 27B | https://console.groq.com/keys |
| OpenRouter | openrouter/free 免费模型路由 | https://openrouter.ai/settings/keys |

进入“设置 → 在线”，分别填写各平台的 API Key，再选择模型并保存。Key 在本机使用 Windows DPAPI 加密保存。右键菜单也可切换模型。

“测试全部在线模型查询速度”测试已配置 Key 的全部模型；没有 Key 的平台跳过。每次发起真实查词请求，不读取查词缓存，不添加测速样例到历史。最近一次测速结果显示在模型名称后，重启后保留。测速也会使用免费额度。

Groq 请保持账号在 Free Plan；开发者付费计划并不自动属于免费使用。应用只提供官方免费计划可调用的文本模型。

OpenRouter 只调用 `openrouter/free`，不使用付费路由或付费模型自动回退。它会自动从当时可用且满足 JSON 输出要求的免费模型中选择，不能保证每次使用同一个模型；免费配额和上游可用性以账号后台为准。

Cerebras 未接入：当前官方说明是绑定支付方式后赠送 5 美元，30 天到期，没有持续免费的层级。
